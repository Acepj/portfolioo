# Amorth Maria — Video Editor & Creative Director

A modern personal portfolio website for **Amorth Maria**, showcasing video editing skills, creative services, selected works, professional information, and contact details.

## 📌 About the Project

This website is designed as a professional portfolio for a video editor and creative director.

It presents Amorth Maria's background, editing skills, services, selected works, university mission and vision, and a contact form for potential projects and collaborations.

## ✨ Features

* Modern portfolio landing page
* Fixed navigation bar
* Hero introduction section
* About section
* Personal information card
* Skills showcase
* Portfolio gallery
* Services section
* Mission and Vision section
* Contact information
* Project inquiry form
* Budget selection
* Project type selection
* Social media links
* Responsive Bootstrap layout
* Bootstrap Icons
* Google Fonts integration

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Custom website styling
* **Bootstrap 5.3.3** – Responsive layout and components
* **Bootstrap Icons 1.11.3** – Interface icons
* **Google Fonts** – Manrope typography

The project loads Bootstrap, Bootstrap Icons, Google Fonts, and a custom `style.css` file.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are present.
4. Make sure the `images` folder contains the required portfolio images.
5. Open `index.html` in a web browser.

For easier development, you can use the **Live Server** extension in Visual Studio Code.

## ⚠️ Notes

* The website depends on Bootstrap 5.3.3.
* Bootstrap Icons are loaded through a CDN.
* Google Fonts are loaded externally.
* The custom styling is contained in `style.css`.
* Several social media links currently use `href="#"`.
* Gallery pagination links currently use `href="#"`.
* The contact form uses `action="#"` and therefore does not currently connect to a backend.
* The Mission and Vision section states that its text can be replaced with official university text.
* The portfolio statistics area is present but its number and label content is currently empty in the provided HTML.
